## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Other scripts:

```bash
npm run build         # production build
npm run lint          # ESLint
npm run format        # Prettier, writes changes
npm run format:check  # Prettier, check only
```
